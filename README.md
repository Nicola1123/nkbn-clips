# nkbn-clips
Public media host for the **NKBN YouTube clipping channel** (@NKBNAgency Shorts).
Long-form variety content (podcasts, sports, cooking, stories...) gets cut into
1080x1920 shorts by `pipeline/clip.py`, pushed here, then published via Buffer MCP.

- Raw video URL: `https://raw.githubusercontent.com/Nicola1123/nkbn-clips/main/clips/<slug>/<slug>.mp4`
- Cover: `clips/<slug>/<slug>-cover.jpg`
- Provenance: `clips/<slug>/source.txt` (origin + timestamps)

Do not rename/delete files that Buffer posts reference.
